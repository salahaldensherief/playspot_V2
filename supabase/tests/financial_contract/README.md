# Financial schema fingerprint gate

`schema_fingerprint.sql` is read-only. It hashes definitions and privileges for every `public`/`private` relation, column, constraint, index, non-internal trigger, policy, function, enum/domain, and database extension. It never selects application table rows. The checked-in `deployed_schema_fingerprint_20261024.json` was obtained through the already-authorized Supabase read-only SQL connector from the PlaySpot target on 24 October 2026. It contains object names and MD5 fingerprints, no function bodies, customer rows, passwords or payment records.

The probe observed 3,607 objects on Postgres major 17, including 23 non-internal `bookings` triggers and the `payments_booking_id_unique` constraint. A matching fingerprint is a necessary restore check, **not** evidence that financial behavior or RLS tests pass. The target can drift after capture; recapture through approved read-only access before using this as a release gate.

To compare an authorized schema-only restore, run the probe against the isolated database with `psql -XAt -v ON_ERROR_STOP=1 -f supabase/tests/financial_contract/schema_fingerprint.sql > restored.json`, then `node supabase/tests/financial_contract/compare_schema_fingerprints.mjs supabase/tests/financial_contract/deployed_schema_fingerprint_20261024.json restored.json`. Exit code 0 means names and hashes match; exit code 1 lists missing, extra and changed objects. `node --test supabase/tests/financial_contract/compare_schema_fingerprints.test.mjs` verifies the comparison logic.

Acquire the schema with Supabase CLI's **schema-only** `db dump` from a separately authorized read-only connection, or use a verified disposable Supabase branch without customer data. Restore into an isolated Postgres 17 environment with matching extensions and role scaffolding. Never use `--data-only`, copy customer rows, commit a connection string, or apply any DDL to the target. The current execution environment has no CLI, direct connection credential or disposable branch, so no schema dump or representative financial integration test has yet run. This tool must not be used to label the synthetic checkout fixture production-equivalent.
