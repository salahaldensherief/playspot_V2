## Scope and interpretation

273 literal request candidates were inventoried from all Dashboard lib/**/*.dart files: 155 RPC calls, 114 `.from` calls (including 3 storage-bucket calls), 4 Edge invoke calls. Mobile has a companion 133-call register. Counts are **lexical call sites**, not unique endpoints or full AST/dataflow coverage. Auth/Realtime/dynamic calls are separately indexed below; a parameter passed via a map variable requires manual resolution. Comments/aliases/dynamic SQL may require further review.

All 155 literal Dashboard RPC names were compared against production public pg_proc. Two call sites target missing functions: get_payment_funds_review and record_payment_funds_custody. Every other literal name resolves; no incompatible p_* argument-name set was detected by the literal-key check. Required/optional argument semantics, nested payload fields, Dart/PostgREST type conversion, response JSON/nullability, cancellation, retries, UI updates, grant effectiveness and concurrent write behavior **are not certified by this check**. They remain IMPLEMENTED BUT UNVERIFIED unless an executed test is specifically cited.

The five initial unresolved candidates were manually split into two missing RPCs and three existing storage buckets; they are not five backend defects. Production buckets promotion-assets and tournament-receipts exist. All inventoried public table names resolve. Demo resolves every literal RPC name in both clients, illustrating deployment drift rather than proving demo correctness.
