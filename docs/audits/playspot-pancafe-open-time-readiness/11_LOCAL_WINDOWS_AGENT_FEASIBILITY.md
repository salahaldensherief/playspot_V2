# Optional local Windows agent feasibility

**DESIGN ONLY / NOT VERIFIED.** A PlaySpot Windows service could pair with a lounge, send authenticated health and station observations, hold a narrowly scoped offline lease and relay signed/idempotent commands to separately installed terminal agents. Installation, revocation, updates, service recovery, audit, encryption, user disclosure and conflict resolution require an explicit threat model and Windows pilot. Dashboard must distinguish command accepted from applied and unknown.

A PC terminal agent may enforce a session only on an owned, consented Windows workstation. PlayStation logical billing is separate from console or monitor physical control. No electric switching, smart-plug prototype, automatic power interruption, or claimed PC lock was implemented. Hardware certification, ratings, operating frequency and safe manual override would be prerequisites to any future control research. See [bridge](10_VENDOR_BRIDGE_ARCHITECTURE.md).
